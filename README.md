# Akram Khan S — Portfolio Website

A responsive, static portfolio website for presenting Akram's full-stack development profile, technical skills, selected projects, education, and contact links.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. The résumé is included at `assets/akram-resume.pdf` and linked from the hero section.

No build step or package installation is required.

## Publish it online

### GitHub Pages
1. Create a GitHub repository, for example `akram-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and copy the public URL.

You can also publish the same static folder using Netlify or Vercel.

## Before sharing

- Check the résumé, contact information, project details, and all links.
- The LearnFlow-AI GitHub link is included as a project repository. Confirm that the repository is public and the project name matches what you want recruiters to see.
- Add project demo links or screenshots only when you have a working demo or genuine screenshots.
- The page uses Google Fonts from an external CDN; it falls back to system fonts if they are unavailable.

## Built with

HTML5, CSS3, and vanilla JavaScript. Responsive layout, mobile navigation, project cards, résumé link, and direct email/LinkedIn/GitHub links.
